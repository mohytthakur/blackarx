# WeldSight

WeldSight is a focused visual inspection workspace for reviewing weld images and organizing inspection history.

## Run locally

1. `npm install`
2. `npm run dev`

## Deploy

Deploy the project to Vercel. The included `vercel.json` keeps the single-page app routes working after deployment.

## Inspection scoring

The current inspection response is simulated in the app so the full review experience can be tested without an external vision service. Replace the marked scoring block with the response from your approved production vision API when that service is ready.
